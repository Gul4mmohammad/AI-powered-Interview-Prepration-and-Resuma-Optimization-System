# AI-powered-Interview-Prepration-and-Resuma-Optimization-System
An AI-powered full-stack web application for personalized interview preparation, skill-gap analysis, and job-specific resume optimization using Generative AI.

AI-Powered Interview Preparation and Resume Optimization System is a full-stack web application designed to help job seekers prepare for specific roles. The system analyzes a user's resume, self-description, and target job description using Generative AI to generate personalized interview questions, identify skill gaps, provide a preparation plan, and create a tailored resume in PDF format.
